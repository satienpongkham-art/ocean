## ติดตั้ง

1. ล็อกอิน GitHub ใน Chrome (repo เป็นส่วนตัว)
2. พิมพ์ในช่องที่อยู่: `github.com/satienpongkham-art/ocean/releases/download/system-latest/System.apk`
   (หรือเปิดหน้า **Releases** → **System (ล่าสุด)** → แตะ `System.apk`) — ได้ไฟล์ APK ตรง ๆ ไม่ต้องแตก zip
3. แตะไฟล์ `System.apk` ที่โหลดมา → **ติดตั้ง**
4. ถ้าขึ้นว่าไม่อนุญาต: กด **การตั้งค่า** → เปิด **อนุญาตจากแหล่งนี้** · ถ้า Play Protect เตือน: **รายละเอียดเพิ่มเติม** → **ติดตั้งต่อไป**
5. อัปเดตรอบต่อไป: โหลดลิงก์เดิมแล้วติดตั้งทับได้เลย ข้อมูลไม่หาย (ลงนามด้วยคีย์เดียวกัน)

> ไฟล์ zip ในหน้า Actions (Artifacts) ยังมีอยู่ แต่ตัวแตก zip ของมือถือบางรุ่นแตกไฟล์ไม่ครบ → "ไฟล์แอปมีปัญหา" ให้ใช้ลิงก์ข้างบนแทน

## ตั้งค่าครั้งแรก (สำคัญ — ไม่ตั้งแล้วป๊อปอัปจะไม่เด้ง)

ทำตามขั้นตอนในหน้า onboarding ของแอป แล้วเช็คให้ครบ:

- **การแจ้งเตือน** → อนุญาต
- **การแจ้งเตือนเต็มหน้าจอ** (ตั้งค่า → แอป → System → การแจ้งเตือน) → เปิด
- **การปลุกและการเตือน** (Alarms & reminders) → อนุญาต
- **แบตเตอรี่** (ตั้งค่า → แอป → System → แบตเตอรี่) → **ไม่จำกัด**
- Samsung: ตั้งค่า → การดูแลอุปกรณ์ → แบตเตอรี่ → ขีดจำกัดการใช้งานเบื้องหลัง → **แอปที่ไม่เข้าสู่สลีป** → เพิ่ม System
- **ข้อมูลจริง** (หน้า onboarding หรือแท็บ MENU → DATA):
  - **Health Connect** → อนุญาต การนอน + ก้าวเดิน · ใน Samsung Health: ตั้งค่า → Health Connect → เปิดซิงก์
  - **เวลาใช้งานแอป** (Usage access) → เปิดให้ System · ใช้ประมาณเวลานอนจากการเปิด/ปิดจอ ระหว่างยังไม่มีนาฬิกา
  - **กิจกรรมการเคลื่อนไหว** → อนุญาต · ใช้นับก้าว
- กดปุ่ม **ทดสอบใน 10 วินาที** (หน้า "ทดสอบหน้าต่างเด้ง") → ล็อกจอรอ 10 วินาที → ต้องเด้งเต็มจอทับหน้าล็อก

## มีอะไรบ้าง

แถบล่าง: **STATUS · QUEST · GATE · SHOP · MENU**

- **QUEST** — หน้าต่าง QUEST INFO แยกหมวด (ร่างกาย · สุขภาพ · ภาพลักษณ์ · จิตใจ · ปัญญา · เสริม) พร้อมตัวละครของเราในท่าของหมวดนั้น ตัวนับ `[x/y]` CAUTION และนาฬิกานับถอยหลัง · PENALTY / GATE / BOSS ขึ้นเป็นหน้าต่างของตัวเอง
- **STATUS** — ตัวละครที่เปลี่ยนร่างตามผลจริง (5 ร่าง: รอบเอวลด + แรงก์ STR) ใส่ชุด อาวุธ ออร่า · ฉายา · อาชีพ · EXP · สเตตัส 6 ด้าน · กระเป๋าไอเทม (ใช้ได้) · กราฟน้ำหนัก รอบเอว วิดพื้นสูงสุด ชั่วโมงนอน
- **GATE** — ประตูมิติสุ่มเปิดวันละ 0–2 ครั้ง 45 นาที (มีหน้าต่างเด้งเตือน) · ผ่าน = G + ไอเทม · ไม่ผ่าน = บทลงโทษ · **บอสวันอาทิตย์**: วิดพื้นรวดเดียว + แพลงก์ + รอบเอว/น้ำหนัก ดีขึ้นจริง = ดาเมจ ชนะ = เลเวลอัป · **เปลี่ยนอาชีพ** ที่เลเวล 10
- **SHOP** — ของแต่งตัวละครซื้อด้วย G · VAULT บันทึกเงินเก็บจริง · ของรางวัลจริงตั้งเอง แลกเมื่อเงินเก็บถึง · ผูก TWIN (ซื้อของจริง = ได้ของในเกม)
- **MENU** — MEAL PLAN · BODY LOG · JOURNAL · MAINTENANCE · TITLES (ฉายา +5% G) · ตั้งค่าข้อมูลจริง
- ป๊อปอัปเต็มจอ: เควสต์เช้า · มื้ออาหาร · เตือนนอน · ประตูเปิด

### เควสต์ร่างกาย (สะสมทั้งวัน แบ่งกี่เซ็ตก็ได้ · ทุกวันที่ 5 ลดเหลือ 70% ให้ร่างกายฟื้น)

| ท่า | วันแรก | วันที่ 14 | วันที่ 60+ |
|---|---|---|---|
| วิดพื้น | 50 | 100 | 200 |
| สควอท | 100 | 150 | 200 |
| ซิทอัพ | 50 | 100 | 200 |
| เชือกกระโดด | 3 นาที | 5 นาที | 10 นาที |
| ก้าวเดิน | 6,000 | 7,000 | 8,000 (วันที่ 28+) |

### วิธีนับว่าเควสต์สำเร็จ

| เควสต์ | ตรวจด้วย |
|---|---|
| วิดพื้น / สควอท / ซิทอัพ / เชือก / เดินหลังมื้อ / ประตู | เซนเซอร์มือถือ (กดเองไม่ได้) |
| ก้าวเดิน | Health Connect (Samsung Health) หรือเซนเซอร์นับก้าว — อัตโนมัติ |
| เข้านอนตรงเวลา · ปิดจอ 30 นาทีก่อนนอน | ตรวจอัตโนมัติทุกเช้าจากเวลานอนจริง (Health Connect หรือการเปิด/ปิดจอ) · ถ้ายังไม่อนุญาต ต้องกดยืนยันเอง |
| ตื่นตามเวลา | กด "ยอมรับเควสต์" ในป๊อปอัปเช้า หรือแตะใน QUEST ภายใน 60 นาทีหลังเวลาตื่น |
| ชั่งน้ำหนัก | BODY LOG · ดื่มน้ำ: ปุ่ม +250 มล. · ไดอารี่: ≥ 3 บรรทัด |
| อื่น ๆ (กันแดด แก้หลังค่อม อ่านหนังสือ Maintenance ฯลฯ) | ติ๊กเอง |

- วันแรกที่ติดตั้งไม่มีบทลงโทษ · Maintenance ขึ้นวันละไม่เกิน 2 อย่าง
- ปุ่ม "บาดเจ็บ" ลดเป้าที่เหลือครึ่งหนึ่งได้วันละครั้งต่อเควสต์ (ไม่ทำให้เควสต์สำเร็จเอง)
- ถ้าสิทธิ์ไหนหลุด แอปจะขึ้นแถบ [ WARNING ] ด้านบน แตะเพื่อไปแก้
- อัปเดตจาก v0.1.0: ข้อมูลเดิมอยู่ครบ · เควสต์ใหม่ (ซิทอัพ ก้าว ฯลฯ) เริ่มขึ้นในกระดานของวันถัดไป

## เช็คลิสต์ทดสอบบนเครื่องจริง (Flip)

- [ ] ปุ่ม "ทดสอบใน 10 วินาที" จาก onboarding → เด้งบนหน้าล็อก
- [ ] ป๊อปอัปเด้งขณะพับเครื่อง (ขึ้นแจ้งเตือนที่จอนอก แล้วกางดูเต็มจอ)
- [ ] ป๊อปอัปเช้าเด้งตามเวลาตื่นจริง
- [ ] ป๊อปอัปมื้ออาหารเด้งทุกเวลามื้อ
- [ ] รีบูตเครื่อง → ป๊อปอัปยังเด้งตามเวลา
- [ ] วิดพื้น 10 ครั้ง (วางมือถือใต้หน้าอก) นับได้ 10 ± 1
- [ ] สควอท 10 ครั้ง (มือถือในกระเป๋ากางเกงด้านหน้า) นับได้ 10 ± 1
- [ ] กระโดดเชือก 60 วินาที นับเวลาได้ใกล้เคียง
- [ ] ยกมือถือขึ้นระหว่างวิดพื้น → ขึ้นเตือนและไม่นับ
- [ ] แบตเหลือน้อย (โหมดประหยัด) → ป๊อปอัปยังเด้ง
- [ ] ซิทอัพ 10 ครั้ง (นอนหงาย มือถือแนบหน้าอก) นับได้ 10 ± 1
- [ ] เดินหลังมื้อ 800 ก้าว = 1 รอบ
- [ ] เช้าวันถัดไป: เควสต์เข้านอน/ปิดจอ ถูกตรวจอัตโนมัติ และชั่วโมงนอนขึ้นใน STATUS
- [ ] ก้าวเดินใน QUEST ตรงกับ Samsung Health
- [ ] ประตูเปิด → หน้าต่างเด้ง → นับได้เฉพาะในเวลาประตู
