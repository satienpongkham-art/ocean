# System — v0.1.0 (รอบ 1)

แอป Android แบบเกม ที่ออกเควสต์ประจำวัน ตรวจว่าทำจริง และให้ EXP/เลเวลตามผลที่วัดได้จริง
สเปก: `docs/superpowers/specs/2026-11-08-system-design.md` · แผนรอบ 1: `docs/superpowers/plans/2026-11-08-system-round1.md`

> ข้อมูลส่วนตัว (น้ำหนัก รอบเอว ไดอารี่ มื้ออาหาร) เก็บในเครื่องเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์ และไม่มีใน repo นี้

## ติดตั้ง

1. เปิด GitHub → repo นี้ → แท็บ **Actions** → เวิร์กโฟลว์ **system-app** → เลือกรันล่าสุดที่เป็นสีเขียว
2. เลื่อนลงไปที่ **Artifacts** → กดดาวน์โหลด `system-app-debug` (ได้ไฟล์ .zip)
3. แตก zip บนมือถือ จะได้ `app-debug.apk` → แตะเพื่อติดตั้ง
4. ถ้าขึ้นว่าไม่อนุญาต: ตั้งค่า → แอป → (แอปที่ใช้เปิดไฟล์ เช่น My Files / Chrome) → **ติดตั้งแอปที่ไม่รู้จัก** → อนุญาต
5. อัปเดตรอบต่อไป: ติดตั้งทับได้เลย ข้อมูลไม่หาย (ลงนามด้วยคีย์เดียวกัน)

## ตั้งค่าครั้งแรก (สำคัญ — ไม่ตั้งแล้วป๊อปอัปจะไม่เด้ง)

ทำตามขั้นตอนในหน้า onboarding ของแอป แล้วเช็คให้ครบ:

- **การแจ้งเตือน** → อนุญาต
- **การแจ้งเตือนเต็มหน้าจอ** (ตั้งค่า → แอป → System → การแจ้งเตือน) → เปิด
- **การปลุกและการเตือน** (Alarms & reminders) → อนุญาต
- **แบตเตอรี่** (ตั้งค่า → แอป → System → แบตเตอรี่) → **ไม่จำกัด**
- Samsung: ตั้งค่า → การดูแลอุปกรณ์ → แบตเตอรี่ → ขีดจำกัดการใช้งานเบื้องหลัง → **แอปที่ไม่เข้าสู่สลีป** → เพิ่ม System
- กดปุ่ม **ทดสอบใน 10 วินาที** (หน้า "ทดสอบหน้าต่างเด้ง") → ล็อกจอรอ 10 วินาที → ต้องเด้งเต็มจอทับหน้าล็อก

## มีอะไรในรอบ 1

- Onboarding (ข้อมูลร่างกาย เวลาตื่น/นอน เวลามื้อ งบ อุปกรณ์ที่มี)
- QUEST LOG: กระดานเควสต์รายวัน (เช้า/กลางวัน/ฝึก/กลางคืน) + เควสต์ Maintenance ที่ถึงรอบ + PENALTY จากเมื่อวาน
- STATUS: เลเวล EXP สเตตัส 6 ด้าน แรงก์ และ CONDITION จากชั่วโมงนอน
- ป๊อปอัปเต็มจอ: เควสต์ประจำวัน (เวลาตื่น) · มื้ออาหาร (ตามเวลามื้อ พร้อมเมนู วิธีสั่ง ราคา) · เตือนนอน (ก่อนนอน 30 นาที)
- ตัวนับด้วยเซนเซอร์มือถือ: วิดพื้น (เซนเซอร์ระยะ) · สควอท (มือถือในกระเป๋ากางเกง) · กระโดดเชือก (ถือ/ใส่กระเป๋า)
- BODY LOG: น้ำหนัก รอบเอว ชั่วโมงนอน น้ำดื่ม (+250 มล.)
- MEAL PLAN: จัดเมนูทั้งวันให้อยู่ในแคลอรี/โปรตีน/งบ · สลับเมนู · บันทึกว่ากินแล้ว
- MAINTENANCE: หลอดความทนทานของกิจวัตร (โกนหนวด ตัดเล็บ ตัดผม เปลี่ยนปลอกหมอน ฯลฯ)
- ไดอารี่ (≥ 3 บรรทัด + อารมณ์ = เควสต์สำเร็จ)

### วิธีนับว่าเควสต์สำเร็จ (รอบ 1)

| เควสต์ | ตรวจด้วย |
|---|---|
| วิดพื้น / สควอท / เชือก | เซนเซอร์มือถือ (กดเองไม่ได้) |
| ชั่งน้ำหนัก | กรอกน้ำหนักใน BODY LOG |
| ดื่มน้ำ | ปุ่ม +250 มล. |
| ไดอารี่ | บันทึก ≥ 3 บรรทัด |
| ตื่นตามเวลา | กด "ยอมรับเควสต์" ในป๊อปอัปเช้า หรือแตะเควสต์ใน QUEST LOG ภายใน 60 นาทีหลังเวลาตื่น |
| เข้านอนตรงเวลา | กด "เข้านอนแล้ว" ในป๊อปอัปก่อนนอน หรือแตะเควสต์ใน QUEST LOG (ช่วง 60 นาทีก่อน ถึง 30 นาทีหลังเวลานอน) — รอบ 2 จะใช้ Health Connect แทน |
| อื่น ๆ (ครีมกันแดด อ่านหนังสือ Maintenance ฯลฯ) | ติ๊กเอง |

- วันแรกที่ติดตั้งไม่มีบทลงโทษ · Maintenance ขึ้นวันละไม่เกิน 2 อย่าง
- ปุ่ม "บาดเจ็บ" ลดเป้าที่เหลือครึ่งหนึ่งได้วันละครั้งต่อเควสต์ (ไม่ทำให้เควสต์สำเร็จเอง)
- ถ้าสิทธิ์ไหนหลุด แอปจะขึ้นแถบ [ WARNING ] ด้านบน แตะเพื่อไปแก้

## ยังไม่มี (รอบถัดไป)

- **รอบ 2 — โหมดโหด:** ล็อกแอป · PENALTY โอนเงินเข้าเซฟ · Emergency/Hidden Quest · เวลาหน้าจอ · Health Connect · ประเมินรายสัปดาห์ · LEVEL UP

## เช็คลิสต์ทดสอบบนเครื่องจริง (Flip)

- [ ] ปุ่ม "ทดสอบใน 10 วินาที" จาก onboarding → เด้งบนหน้าล็อก
- [ ] ป๊อปอัปเด้งขณะพับเครื่อง (ขึ้นแจ้งเตือนที่จอนอก แล้วกางดูเต็มจอ)
- [ ] ป๊อปอัปเช้าเด้งตามเวลาตื่นจริง
- [ ] ป๊อปอัปมื้ออาหารเด้งทุกเวลามื้อ
- [ ] รีบูตเครื่อง → ป๊อปอัปยังเด้งตามเวลา
- [ ] วิดพื้น 10 ครั้ง (วางมือถือใต้หน้าอก) นับได้ 10 ± 1
- [ ] สควอท 10 ครั้ง (มือถือในกระเป๋ากางเกงด้านหน้า) นับได้ 10 ± 1
- [ ] กระโดดเชือก 60 วินาที นับเวลาได้ใกล้เคียง
- [ ] ยกมือถือขึ้นระหว่างวิดพื้น → ขึ้นเตือนและไม่นับ
- [ ] แบตเหลือน้อย (โหมดประหยัด) → ป๊อปอัปยังเด้ง
