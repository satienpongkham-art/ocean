# Advisor Desk — แอปส่วนตัวของที่ปรึกษาการเงิน

แอปของ **เสฐียรพงษ์ คำศรี** (Financial Advisor · AIA · รหัสตัวแทน 731462)
ใช้ได้ทั้งมือถือและคอม ติดตั้งเป็นแอปบนหน้าจอหลักได้ และใช้ตอนไม่มีเน็ตได้

## มีอะไรบ้าง

|---|---|

## เปิดใช้งานบนเว็บ (GitHub Pages — ฟรี)
1. เข้า repo บน GitHub → **Settings** → **Pages**
2. Source: **Deploy from a branch** → เลือก branch ที่มีโค้ดนี้ (เช่น `main`) โฟลเดอร์ `/ (root)` → **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/ocean/`
4. เปิดลิงก์ในมือถือ → เมนูแชร์ (iPhone: Safari › แชร์ › **เพิ่มไปยังหน้าจอโฮม** / Android: Chrome › ⋮ › **ติดตั้งแอป**)

> ข้อมูลลูกค้า **ไม่ได้** อยู่ใน GitHub — อยู่ในเครื่องที่ใช้ + Google Sheets ของคุณเท่านั้น

## อัปเดตข้อมูลแผนเอง
ข้อมูลแผนแยกเป็นไฟล์อ่านง่ายในโฟลเดอร์ `data/` แก้บน GitHub ได้เลย (กดรูปดินสอ ✎):

| ไฟล์ | เนื้อหา |
|---|---|
| `data/plans-life.js` | ประกันชีวิต (Pay Life Plus, 20 Pay Life, 10/15 Pay Life, Term, Life Protector, Protection 65) |
| `data/plans-health.js` | ประกันสุขภาพ + ชดเชยรายได้ (Health Happy, Health Saver, Health Starter, CI Hero, Infinite Care, HB Extra, HB) |
| `data/plans-ci.js` | โรคร้ายแรง (CI ProCare, SuperCare, CI Plus, Multi-Pay, Care for Cancer, Lady Care, WPCI, TPD …) |
| `data/plans-accident.js` | อุบัติเหตุ AIANPA (พร้อมตารางเบี้ยจริงจากโบรชัวร์) |
| `data/plans-saving.js` | ออมทรัพย์ บำนาญ ผู้สูงอายุ |
| `data/packages.js` | แพ็กเกจ 3 ระดับ |
| `data/cases.js` · `objections.js` · `captions.js` · `profile.js` | Case study · ข้อโต้แย้ง · แคปชั่น · โปรไฟล์เริ่มต้น |

- **แผนปิดรับ:** ใส่ `closing: 'ปปปป-ดด-วว'` (นับถอยหลังอัตโนมัติ) หรือ `closed: true` — Health Happy ตั้งไว้ที่ `2026-11-30`
- **แผนใหม่:** คัดลอกแผนเดิมทั้งก้อน `{ … },` แล้วแก้ `id` (ห้ามซ้ำ) และรายละเอียด
- **ยูนิตลิงก์ (เมื่อได้ใบอนุญาต IC):** สร้าง `data/plans-unitlinked.js` แล้วเพิ่มในไฟล์ `data/plans.js`
- หลังแก้ เปลี่ยนเลข `VERSION` ในไฟล์ `sw.js` เพื่อให้เครื่องที่ติดตั้งแอปไว้โหลดของใหม่

## ที่มาของข้อมูล
- หน้าผลิตภัณฑ์และโบรชัวร์ทางการบน aia.co.th (ตรวจเมื่อ 15 พ.ย. 2569) — ทุกแผนมีลิงก์ไปหน้า AIA และโบรชัวร์
- ตัวอย่างเบี้ยมาจากกรณีตัวอย่างในโบรชัวร์ (ระบุแหล่งทุกครั้ง) — **เบี้ยจริงต้องออกใบเสนอจากระบบ AIA**
- เกณฑ์ภาษี: กรมสรรพากร "ผู้มีเงินได้มีสิทธิหักลดหย่อนอะไรได้บ้าง?" (ปรับปรุง 30 ก.ค. 2567)
- ระบบงานขาย: Al Granum (One Card System, 10:3:1), แนวปฏิบัติสมาชิก MDRT
