# System — แอป Android พัฒนาตัวเองแบบเกม (สเปกการออกแบบ)

- วันที่: 2026-11-08
- สถานะ: ร่างเพื่อรีวิว
- แพลตฟอร์ม: Android อย่างเดียว (ทดสอบหลักบน Samsung Galaxy Z Flip8 · One UI 9 / Android 17)
- หน้าจอตัวอย่าง (mockup): Artifact ส่วนตัวของเจ้าของ (ไม่อยู่ใน repo)

> **ความเป็นส่วนตัว:** repo นี้เป็นสาธารณะ เอกสารนี้จึงไม่มีข้อมูลส่วนตัวของผู้ใช้เลย
> ค่าเฉพาะตัวทั้งหมด (ส่วนสูง น้ำหนัก รอบเอว งบเงิน งาน ฯลฯ) กรอกในแอปตอนตั้งค่าครั้งแรก
> และเก็บในเครื่องเท่านั้น ตัวเลขในเอกสารนี้เป็นค่าเริ่มต้นหรือสูตร ไม่ใช่ข้อมูลจริงของใคร

## 1. เป้าหมาย

"System" คือผู้ช่วยในรูปแบบระบบเกม (ฟีลอนิเมะแนว "ระบบเลเวลอัป") ที่สั่งเควสต์รายวัน
ตรวจว่าทำจริงด้วยเซนเซอร์ ล็อกแอปเมื่อไม่ทำ และให้เลเวลขึ้น**เฉพาะเมื่อร่างกายหรือชีวิตเปลี่ยนจริง**

เกณฑ์ความสำเร็จ:

1. ผู้ใช้เปิดแอปและทำเควสต์ทุกวัน (เป้า: ทำเควสต์หลักครบ ≥ 80% ของวันใน 90 วัน)
2. ตัวชี้วัดจริงดีขึ้น: รอบเอว น้ำหนักเฉลี่ย 7 วัน ความแข็งแรง การนอน
3. หน้าต่าง System เด้งตรงเวลา ≥ 99% ของครั้ง บนเครื่องจริง
4. ไม่มีข้อมูลส่วนตัวออกจากเครื่อง (ยกเว้นไฟล์สำรองที่ผู้ใช้ส่งออกเอง)

หลักการออกแบบที่ยึดตลอด:

- **อิงหลักฐาน:** ทุกเกณฑ์ เป้าหมาย และเควสต์ด้านสุขภาพอ้างอิงแนวทางหรืองานวิจัย (ดูหัวข้อ 21)
  และติดป้ายเมื่อเป็นเกณฑ์ที่ System ตั้งเองหรือหลักฐานอ่อน
- **โหดแต่ไม่พัง:** โหมดโหดจริง แต่มีวันป่วย ความปลอดภัย และกฎไม่ให้บาดเจ็บ
- **ทำจริงยากกว่าโกงไม่ได้ ก็ต้องโกงยากกว่าทำจริง:** ตรวจด้วยเซนเซอร์ เวลาใช้แอป และรูปสุ่ม
- **ไม่ลอกงานใคร:** ฟีลแนวเกมระบบ แต่ชื่อ ภาพ และคำทั้งหมดออกแบบใหม่

## 2. ขอบเขตและข้อจำกัด

อยู่ในขอบเขต:

- แอป Android เนทีฟ (Kotlin + Jetpack Compose) ติดตั้งเองจากไฟล์ APK
- ทุกด้านอยู่ในกระดานเควสต์เดียว: ร่างกาย อาหาร การนอน ผิวและบุคลิก จิตใจ การเรียนรู้ การเงิน งาน กิจวัตร
- จอนอก Flip (FlexWindow) และโหมดพับครึ่ง (Flex Mode)
- ข้อมูลอยู่ในเครื่อง (Room) + ส่งออก/นำเข้าไฟล์สำรอง

ข้อจำกัดที่รู้แล้ว:

- **ไม่ใช้กล้องนับครั้ง** (ผู้ใช้เลือก) ใช้เซนเซอร์มือถือเท่านั้น
- ออกกำลังกายที่บ้านเท่านั้น: บอดี้เวท ดัมเบลคู่ (ค่าเริ่มต้น 5 กก.) เชือกกระโดด
- ยังไม่มีสมาร์ทวอทช์ (ระบบต้องทำงานครบโดยไม่มี และอัปเกรดตัวเองเมื่อมี)
- แอปที่ติดตั้งเองป้องกันการถอนการติดตั้งได้ไม่ 100% (เซฟโหมดปิดได้)
- อ่านเนื้อหาในแอปอื่น (IG / TikTok) ไม่ได้และจะไม่ทำ ใช้เวลาใช้งานแอปและการแชร์เข้ามาแทน

นอกขอบเขต (v1): iOS, เซิร์ฟเวอร์/บัญชีออนไลน์, AI วิเคราะห์รูปในแอป, ติดตามยอดขาย/ค่าคอมมิชชั่น

## 3. การตั้งค่าครั้งแรก (Onboarding)

ลำดับหน้าจอ:

1. **ปลุกระบบ:** แอนิเมชัน `SYSTEM ONLINE` → ตั้งชื่อผู้เล่น
2. **โปรไฟล์:** อายุ ส่วนสูง เพศ (ใช้ในสูตร) ไซส์เสื้อ
3. **ค่า Day 0** (บันทึกเป็นการประเมินครั้งแรก):
   น้ำหนักตอนเช้า · รอบเอวแนวสะดือ · วิดพื้นสูงสุด · แพลงก์สูงสุด · เชือกกระโดดต่อเนื่องสูงสุด ·
   รูปติดตามผลตามมาตรฐาน (หัวข้อ 10.4) · PSS-10 · ระดับ EF SET (ถ้ามี)
4. **ตารางชีวิต:** เวลาตื่น (ค่าเริ่มต้น 07:00) เวลานอน (ค่าเริ่มต้น 23:00) เวลามื้ออาหาร
5. **ของที่มีจริง (Inventory):** อุปกรณ์ออกกำลังกาย สกินแคร์ สายวัด ปลอกแขนมือถือ ฯลฯ
6. **การเงิน:** งบต่อสัปดาห์ วันรับเงิน % กันเงินเก็บ เพดานเติมเกมต่อเดือน
7. **รายการแอป:** แอปที่จะล็อก · แอปที่ไม่ล็อกเด็ดขาด · แอปทำงาน · แอปเรียนภาษา/อ่านหนังสือ
8. **ขอสิทธิ์** (หัวข้อ 17.4) พร้อมคำอธิบายแต่ละสิทธิ์ และพาไปตั้งค่าแบตเตอรี่ของ Samsung
9. **ทดสอบหน้าต่างเด้ง:** ปิดจอแล้วนับ 10 วินาที → หน้าต่าง System ต้องเด้งบนหน้าล็อก

## 4. แกนเกม

### 4.1 EXP = ความพยายาม, ด่านเลเวล = ผลลัพธ์จริง

- EXP ได้จากเควสต์ (หัวข้อ 5) และเติมหลอด
- **EXP เต็มหลอดยังไม่เลเวลอัป** ต้องผ่าน "การประเมินประจำสัปดาห์" ก่อน
- EXP ส่วนเกินเก็บได้สูงสุด 150% ของหลอด แสดงสถานะ `[ LIMIT ]`
- EXP ที่ต้องใช้ต่อเลเวล: `need(L) = 500 + 150 × (L − 1)`
- ผลคือเลเวลขึ้นได้มากสุดสัปดาห์ละ 1 ครั้ง

### 4.2 การประเมินประจำสัปดาห์ (ค่าเริ่มต้น: วันอาทิตย์ 07:00)

หน้าต่างเต็มจอให้วัด: น้ำหนัก (ระบบใช้ค่าเฉลี่ย 7 วันจากการชั่งทุกเช้า) รอบเอว
วิดพื้นสูงสุด แพลงก์สูงสุด เชือกกระโดดต่อเนื่องสูงสุด (ทดสอบท่าใช้เซนเซอร์)

ผ่านด่านเมื่อ **EXP ≥ need(L)** และ **ดีขึ้นอย่างน้อย 1 ตัวชี้วัด** เกินค่าคลาดเคลื่อน:

| ตัวชี้วัด | เกณฑ์ผ่าน |
|---|---|
| รอบเอว | ลดลง ≥ 1.0 ซม. จากค่าที่ดีที่สุดก่อนหน้า |
| น้ำหนักเฉลี่ย 7 วัน | ลดลง ≥ 0.3 กก. |
| วิดพื้นสูงสุด | เพิ่ม ≥ 1 ครั้ง |
| แพลงก์สูงสุด | เพิ่ม ≥ 5 วินาที |
| เชือกกระโดดต่อเนื่อง | เพิ่ม ≥ 10 วินาที |

ด่านแดง (ไม่เลเวลอัปแม้ตัวเลขผ่าน แล้วสั่งเควสต์ฟื้นฟูแทน):

- น้ำหนักเฉลี่ย 7 วันลดเร็วกว่า 1.5% ต่อสัปดาห์
- นอนเฉลี่ย 7 วันต่ำกว่า 6 ชั่วโมง

### 4.3 สเตตัส (คำนวณจากการวัดจริง ไม่มีแต้มให้กดเอง)

| สเตตัส | วัดจาก | เกณฑ์ Rank |
|---|---|---|
| `STR` | วิดพื้นสูงสุดแบบไม่พัก | CSEP/CPAFLA (ACSM พิมพ์ซ้ำ) ชาย 20–29: E ≤16 · D 17–21 · C 22–28 · B 29–35 · A ≥36 · S ≥50 (S = System ตั้งเอง) ตารางตามอายุ/เพศอื่นเก็บในแอป |
| `VIT` | รอบเอว ÷ ส่วนสูง (WHtR) + โบนัสการนอน | NICE: 0.40–0.49 ดี · 0.50–0.59 เสี่ยงเพิ่ม · ≥0.60 เสี่ยงสูง → E ≥0.60 · D 0.55–0.59 · C 0.50–0.54 · B 0.45–0.49 · A <0.45 และ STR ≥ B (การแบ่งย่อย = System ตั้งเอง) |
| `AGI` | เชือกกระโดดต่อเนื่อง · (มีนาฬิกา) หัวใจตอนพัก การฟื้นตัวของหัวใจ VO2max | System ตั้งเอง: E <1 นาที · D 1–2 · C 2–5 · B 5–10 · A 10–15 · S 15+ |
| `CHA` | จำนวนสิวอักเสบจากรูปมาตรฐาน · ความสม่ำเสมอสกินแคร์ 28 วัน · ไมล์สโตนการดูแลตัวเอง · ระดับชาเลนจ์ความมั่นใจ | คะแนนรวม 0–100 → E–S ทุก 20 คะแนน (ประเมินเดือนละครั้ง) |
| `MND` | PSS-10 รายเดือน (0–13 ต่ำ · 14–26 ปานกลาง · 27–40 สูง) + % ทำตามกฎ (เทรด กฎ 24 ชม. เวลาใช้มือถือ) | คะแนนรวม 0–100 → E–S |
| `INT` | EF SET (CEFR) ทุก 3 เดือน + จำนวนหนังสือที่อ่านจบ | A1 = E · A2 = D · B1 = C · B2 = B · C1 = A · C2 = S |

- **Rank รวม** = ค่ากลาง (median) ของ 6 สเตตัส · ได้ S เมื่อทุกสเตตัส ≥ A
- **CONDITION** (แทน HP) คำนวณจากการนอนเมื่อคืน:
  `OPTIMAL` ≥ 7.5 ชม. (EXP +10%) · `NORMAL` 6.5–7.5 ชม. · `FATIGUED` < 6.5 ชม. (ท่าออกกำลังกายลดความหนัก 30%)

### 4.4 เปลี่ยนอาชีพ (ทุก 10 เลเวล)

อีเวนต์เต็มจอ `[ JOB CHANGE ]`: ทดสอบชุดใหญ่ (ทุกตัวชี้วัดในหัวข้อ 4.2) ได้ 1,000 G
ตัวละครพิกเซลเปลี่ยนร่างตาม VIT และ STR และปลดล็อกของ LEGENDARY ในร้านค้า

### 4.5 ตัวละครพิกเซล

- ร่าง 1–6 ผูกกับ Rank ของ `VIT` (รูปร่าง) และ `STR` (กล้าม) จริง
- ไอเทมตกแต่ง (หัวข้อ 13) ซ้อนทับบนร่าง ไม่เปลี่ยนรูปร่าง
- วาดเป็นพิกเซลอาร์ตชุดเดียวกันทั้งหมด (ไม่ใช้ภาพจาก AI)

## 5. เควสต์

### 5.1 ประเภท

| ประเภท | สี | เวลา | ล้มเหลวแล้ว |
|---|---|---|---|
| Daily (หลัก/รอง) | ฟ้า | รีเซ็ต 00:00 ทำให้เสร็จภายใน 23:59 | หลักไม่ครบ → `PENALTY QUEST` วันถัดไป |
| Emergency | ส้ม | เด้งทุกเวลาในช่วงตื่น ทำภายใน 1–2 ชม. | B + C (หัวข้อ 5.5) |
| Hidden: ซ่อนเงื่อนไข | ม่วง | มีคำใบ้ใน `???` | ไม่มีโทษ |
| Hidden: เด้งกะทันหัน | ม่วง/ส้ม | เด้งแบบสุ่ม จำกัด 10 นาที–2 ชม. | ยาก: B + C · ง่าย: พลาดรางวัล |
| Hidden: ไมล์สโตนลับ | ม่วง | ระบบจับได้เอง | — |
| Penalty | แดง | ต้องทำในวันถัดไป | นับล้มเหลวซ้ำ |
| Maintenance | เหลือง/ส้ม | ตามรอบ (หัวข้อ 10.2) | หลอดหมด → เป็นเควสต์หลัก + CHA ลดชั่วคราว |
| Chain | ตามหมวด | ขั้นต่อขั้น เช่น ซื้อกันแดด → ทากันแดดทุกเช้า | — |
| Legendary | ทอง | ระยะยาว เช่น ซื้อสมาร์ทวอทช์ใน 90 วัน | บันทึกว่าล้มเหลว |
| Meal | ทอง | เด้งตรงเวลามื้อ | ไม่มีโทษ (บันทึกแบบประมาณได้) |

### 5.2 กระดานเควสต์รายวัน

- จัดกลุ่ม: เช้า · ระหว่างวัน · ฝึกร่างกาย (ภายใน 23:59) · คืน
- **ทุกด้านเป็นเควสต์หลักตั้งแต่ Day 1** แต่ปริมาณเริ่มน้อยแล้วเพิ่มทุกสัปดาห์
- ตัวอย่าง Day 1: ตื่นก่อนเวลา · ชั่งน้ำหนัก+วัดเอว · แปรงฟัน/ล้างหน้า/กันแดด (หรือ chain ซื้อกันแดด) ·
  ไม่มีน้ำอัดลมหวาน · อ่านหนังสือ 5 หน้า · อังกฤษ 15 นาที · วิดพื้น 10 · สควอท 20 ·
  ไดอารี่ 3 บรรทัด · นอนก่อนเวลา · (รอง) น้ำ 2.5 ลิตร · เชือกกระโดด 90 วินาที · ครัวปิด 21:00 · รายจ่ายไม่เกินงบ
- EXP: หลัก 20–40 · รอง 10–20 · ลับ 50–100 · Emergency 40–80
- G (เงินในเกม): Daily ครบทั้งวัน ≈ 50 G (หลักชิ้นละ 4 G + โบนัสครบ 10 G) · Emergency 80–150 · Hidden 150–300 ·
  ผ่านประเมิน 150 · เลเวลอัป 100 · เปลี่ยนอาชีพ 1,000

### 5.3 ตัวสร้างเควสต์ (Quest Engine)

อินพุต: วันที่ · เลเวล · Day number · CONDITION · Inventory · รอบ Maintenance · ประวัติการฝึก 7 วัน ·
ตารางชีวิต · ปฏิทิน (วันป่วย)

กฎ:

1. สร้างกระดานวันใหม่ตอน 00:00 แบบกำหนดผลได้ซ้ำ (seed = วันที่ + โปรไฟล์) เพื่อทดสอบได้
2. ปริมาณการฝึกมาจากโปรแกรม (หัวข้อ 6) × ตัวคูณ CONDITION
3. ห้ามสั่งฝึกกล้ามมัดเดิมแบบหนักซ้ำภายใน 48 ชม.
4. ปริมาณจาก Emergency นับรวมเป้าการฝึกรายสัปดาห์
5. ถ้าของใน Inventory ไม่มี → สร้าง Chain quest ให้ไปหามาก่อน
6. สลับรูปแบบเควสต์รองไม่ให้ซ้ำติดกันเกิน 2 วัน (กันเบื่อ)

### 5.4 กติกาเวลาเด้ง

- ไม่เด้งช่วงนอน (ค่าเริ่มต้น 23:00–07:00)
- ไม่เด้งขณะ Activity Recognition ตรวจว่า `IN_VEHICLE` → เลื่อนไปเด้งเมื่อออกจากสถานะนั้น
- Emergency สุ่ม 0–2 ครั้งต่อวัน ห่างกันอย่างน้อย 3 ชม.
- Meal เด้งตรงเวลามื้อที่ตั้งไว้ (ไม่มีข้อความเตือนล่วงหน้า)

### 5.5 บทลงโทษ

- Daily หลักไม่ครบ → `PENALTY QUEST` วันถัดไป (ฝึกเพิ่ม ≈ 20 นาที / เพิ่มจำนวนครั้ง) + ล็อกแอปจนกว่าจะเสร็จ
- Emergency / Hidden แบบยากล้มเหลว → **B + C**:
  - B: วันถัดไปฝึกหนักขึ้น (เพิ่มจำนวนครั้ง ≈ 20 นาที) ตรวจด้วยเซนเซอร์
  - C: กองทุนลงโทษ โอนเงินจริง 50–100 บาท (ตั้งได้) เข้าบัญชีเงินเก็บที่ห้ามแตะ 30 วัน
    แนบสลิปภายใน 24 ชม. ไม่ส่ง = ล้มเหลวซ้ำ
- **ไม่ใช้การอดอาหารเป็นบทลงโทษ** (เสียกล้าม เสี่ยงวงจรอด-กินหนัก)
- ไม่รีเซ็ตเลเวล (งานด้าน Gamification เตือนว่าบทลงโทษหนักทำให้เลิกใช้)

## 6. โปรแกรมฝึก

### 6.1 ความแข็งแรง

- หลัก Progressive Overload + ฝึกแต่ละกล้ามเนื้อ ≥ 2 ครั้ง/สัปดาห์ และ ≥ 10 เซ็ต/สัปดาห์ (Schoenfeld 2016–2017)
- **วิดพื้น:** Day 1 รวม 10 ครั้ง → **รวม 100 ครั้ง/วันใน Day 30** (เพิ่มเป็นขั้น มีวันเบาทุก 4–5 วัน)
  วันที่ 30 = บอส "100 ครั้งภายในเวลาที่กำหนด" · 100 ครั้งติดกัน = เป้าระยะยาวในบททดสอบเปลี่ยนอาชีพ
- **สควอท:** Day 1 รวม 20 → เพิ่มตามโปรแกรม
- **แพลงก์:** ปลดล็อกเลเวล 2 เริ่ม 3 × 20 วินาที
- **ดัมเบล:** Row · Shoulder Press · RDL · Curl · Reverse Fly (เน้นหลังช่วยหลังค่อม)
  ไม่มีปลอกแขน → จับเวลาเซ็ต + ยืนยันเอง (ปลอกแขน = Chain quest สัปดาห์แรก)
- เพิ่มน้ำหนักดัมเบลไม่ได้ → เพิ่มจำนวนครั้ง จังหวะช้า (tempo) และเซ็ต

### 6.2 คาร์ดิโอและโซนหัวใจ

- HRmax ประมาณ = 208 − 0.7 × อายุ (Tanaka) · ใช้ Karvonen เมื่อมีหัวใจตอนพักจากนาฬิกา

| โซน | % HRmax | ความรู้สึก (Talk Test) | ใช้ทำอะไร |
|---|---|---|---|
| Z1 | 50–60% | เบามาก | เดิน 10 นาทีหลังมื้ออาหาร |
| Z2 | 60–70% | พูดเป็นประโยคได้ ร้องเพลงไม่ได้ | คาร์ดิโอหลัก |
| Z3 | 70–80% | พูดได้ทีละคำ | ช่วงกลางของ Emergency |
| Z4–Z5 | 80–100% | หอบ พูดไม่ได้ | อินเทอร์วัลสั้น 1–2 ครั้ง/สัปดาห์ |

- เป้า: Z2 เริ่ม 60 นาที/สัปดาห์ → 150 นาที/สัปดาห์ในสัปดาห์ 4–6 (WHO 150–300 นาทีระดับปานกลาง)
- Z4–5 เริ่มสัปดาห์ 3 (เช่น เชือกกระโดดเร็ว 30 วินาที × 6)
- กิจกรรม Z2 ในบ้าน: ย่ำเท้าเร็ว ก้าวขึ้นลงขั้นบันได เชือกจังหวะเบา ชกลม
- ไม่มีนาฬิกา: Talk Test + RPE 1–10 หลังเซ็ต · มีนาฬิกา: เวลาในโซนจาก Health Connect (ตรวจเควสต์อัตโนมัติ)
- ตัวชี้วัดความฟิต: หัวใจตอนพักตอนเช้า · การฟื้นตัวของหัวใจ 1 นาที (≤ 12 bpm = สัญญาณเตือน, Cole 1999) ·
  ความเร็วที่ทำได้ใน Z2 · VO2max (ถ้านาฬิการองรับ)

### 6.3 แม่แบบ Emergency Quest (ต้องมีผลต่อร่างกายจริง)

| แม่แบบ | ตัวอย่าง LV 1 |
|---|---|
| EMOM 10 นาที | วิดพื้น 6 + สควอท 10 ทุกต้นนาที |
| HIIT เชือก | 5 × 1 นาที พัก 30 วินาที |
| Tabata 4 นาที | สควอทกระโดด / Burpee |
| ดัมเบลคอมเพล็กซ์ | Row + Press + RDL × 3 รอบ |
| Z2 ฉุกเฉิน | ย่ำเท้า/ชกลม 20 นาทีในโซน 2 |
| ไม่ใช่ร่างกาย | อ่าน 20 หน้า · โพสต์กลุ่ม 5 กลุ่ม · จัดห้อง 15 นาที |

อ้างอิงแนวคิด "exercise snacks" / VILPA (Stamatakis 2022, Jenkins 2019)

### 6.4 ความปลอดภัย

- เจ็บแปลบที่ข้อต่อ → หยุดทันที (ปุ่ม "เจ็บ" ในหน้าฝึก บันทึกและลดความหนักอัตโนมัติ)
- วันป่วย/บาดเจ็บ 2 ครั้ง/เดือน → เควสต์เปลี่ยนเป็นยืดเหยียดเบาๆ (ไม่ปลดล็อกฟรี)
- CONDITION `FATIGUED` → ลดความหนัก 30%

## 7. นับครั้งด้วยเซนเซอร์

| ท่า | วางมือถือ | สัญญาณ | นับเมื่อ | กันโกง |
|---|---|---|---|---|
| วิดพื้น | วางราบบนพื้นใต้อก | Proximity + Accelerometer | proximity near→far ครบรอบ | ความเร่งต้องนิ่ง (เครื่องอยู่กับพื้น) · ช่วงห่างระหว่างครั้ง 0.6–6 วินาที |
| สควอท | กระเป๋ากางเกงหน้า | Gravity/rotation vector (มุมต้นขา) | มุมต้นขาเปลี่ยน ≥ 70° แล้วกลับ | ต้องลงถึงเกณฑ์ (ลงครึ่งเดียว = INVALID) · ช่วงห่าง 0.8–8 วินาที |
| ลุกนั่ง/ครันช์ | ถือแนบอก | มุมเอียงลำตัว | เอียง ≥ 45° แล้วกลับ | ช่วงห่าง 0.8–8 วินาที |
| แพลงก์ | วางบนหลังช่วงล่าง | มุมเอียง + ความนิ่ง | จับเวลาเมื่อมุมอยู่ในช่วง ±12° | ก้นตก/โด่ง → เวลาหยุด |
| เชือกกระโดด / Jumping Jack | กระเป๋ากางเกง | Accelerometer (ขนาดเวกเตอร์) | จุดยอดเกินเกณฑ์ที่ปรับอัตโนมัติ | ความถี่ 1–4 ครั้ง/วินาที · รูปคลื่นต้องคล้ายการกระโดด |
| ดัมเบล | ปลอกแขน | Gyroscope | รอบการหมุนข้อศอก/ไหล่ | ช่วงห่าง 1–8 วินาที |

- ระบบตรวจ "จังหวะมนุษย์": เขย่ามือถือถี่ผิดธรรมชาติ = ไม่นับ
- โหมดอัดข้อมูลเซนเซอร์ (Sensor Recorder) สำหรับปรับเกณฑ์จากการเคลื่อนไหวจริงของผู้ใช้
- ตัวนับเป็นฟังก์ชันบริสุทธิ์ (รับลำดับค่าเซนเซอร์ → ส่งเหตุการณ์ REP/INVALID) เพื่อทดสอบด้วยข้อมูลที่อัดไว้
- ทำงานใน foreground service ระหว่างฝึก · เสียงนับและการสั่นทุกครั้ง

## 8. อาหาร

### 8.1 เป้าหมาย

- พลังงานที่ใช้ต่อวัน (TDEE) = Mifflin-St Jeor × ตัวคูณกิจกรรม · เป้ากิน = TDEE − 500 kcal (ACSM)
- โปรตีน 1.6–2.2 ก./กก./วัน (Morton 2018, ISSN) · คนน้ำหนักเกินใช้ค่าต่อน้ำหนักเป้าหมาย
- ปรับเป้าอัตโนมัติทุก 2 สัปดาห์จากแนวโน้มน้ำหนักเฉลี่ย 7 วัน
- น้ำ: ค่าเริ่มต้น 2.5 ลิตร/วัน (EFSA ≈ 2.5 ลิตรรวมจากอาหารสำหรับผู้ชาย + อากาศร้อน/ออกกำลังกาย) ปรับได้ บันทึกทีละ 250 มล.

### 8.2 เควสต์อาหาร (แบบ A: กฎ)

ไม่มีน้ำอัดลมหวาน (สูตรไม่มีน้ำตาลได้ในสัปดาห์ 1–2) · กาแฟหวานน้อย → ไม่หวาน วันละแก้ว (สัปดาห์ 3–4) ·
ครัวปิด 21:00 · โปรตีนทุกมื้อ · วันดื่มแอลกอฮอล์ = เควสต์ "คุมความเสียหาย"

### 8.3 ระบบเลือกเมนู (แบบ B + System เลือกให้)

- ฐานข้อมูลเมนู ~100–150 รายการ: ร้านอาหารตามสั่ง · 7-Eleven · ร้านเส้น · สุกี้ · อาหารบ้าน (แบบประมาณ)
- แต่ละเมนู: ชื่อ · หมวด · kcal · โปรตีน · ราคาโดยประมาณ · คำสั่งร้าน ("น้ำมันน้อย ไข่ต้มแทนไข่ดาว") · sprite พิกเซล
- **ค่าทั้งหมดเป็นค่าประมาณ ±20%** และติดป้ายในแอป
- MEAL PLAN รายวัน: 4 มื้อ (เช้า กลางวัน เย็น ของว่าง) · วงแหวน KCAL / PROTEIN / BUDGET ·
  ไทม์ไลน์ DONE / NOW / NEXT · สุ่มใหม่ทีละมื้อ
- "ให้ System จัดเมนูทั้งวัน": ค้นทุกชุดผสม เลือกคะแนนสูงสุด
  `score = 3 × protein − 0.4 × |(target − 150) − kcal| − 0.2 × price` โดย `price ≤ งบวัน`
- **Meal popup** ตรงเวลามื้อ (มือถือ + จอนอก): ภาพอาหารพิกเซล · ชื่อเมนู · kcal/P/ราคา · "พูดกับร้านว่า" ·
  เหลือ kcal/งบเท่าไรหลังมื้อนี้ · ปุ่ม กินตามนี้ (+15 EXP) / สลับ / กินอย่างอื่น (บันทึก S/M/L)

## 10. ผิว บุคลิก และกิจวัตร

### 10.1 สกินแคร์และการดูแลตัวเอง (แนวทาง AAD / ADA)

ล้างหน้าอ่อนโยนเช้า-เย็นและหลังเหงื่อออก · มอยส์เจอไรเซอร์ · กันแดด SPF 30+ ทุกเช้า ·
ตัวยาที่มีหลักฐาน (Niacinamide, Azelaic acid, Adapalene) เป็น Chain quest ·
หลุมสิว/ฟัน → เควสต์พิเศษ "ไปพบแพทย์ผิวหนัง / ทันตแพทย์" · ป้ายระดับหลักฐานในทุกเควสต์

### 10.3 การแต่งตัว (3 ขั้น ผูกกับรอบเอว)

1. ชุดเปลี่ยนผ่าน (ตอนนี้): เสื้อยืดสีเข้มเรียบ 2–3 ตัว · เชิ้ต/โอเวอร์เชิ้ต 1 · กางเกงขาตรงสีเข้ม 1
2. รอบเอวลด 5 ซม.: กางเกงไซส์ใหม่ · โปโล
3. WHtR < 0.5: เชิ้ตพอดีตัว · ชิโน่ · รองเท้าผ้าใบขาว · เข็มขัด

หลักสไตลิสต์ (ติดป้าย): ความพอดีสำคัญสุด · เครื่องประดับเด่น 1 ชิ้น โลหะโทนเดียว · ผ้าระบายร้อนสำหรับอากาศไทย ·
ทองรูปพรรณมีค่ากำเหน็จ ถ้าออมเงินใช้ทองแท่ง · ทุกการซื้อผ่านกฎ 24 ชม. + งบ VAULT

### 10.4 รูปติดตามผลมาตรฐาน

ระยะ 1–1.5 เมตร · กล้องระดับสายตา · แสงเดิม · มีเส้นนำในกล้อง · หน้าตรง/ข้าง/ทั้งตัว ·
เก็บในพื้นที่ส่วนตัวของแอปเท่านั้น · เปรียบเทียบ Day 0 / 30 / 90 แบบเลื่อนดู

## 11. จิตใจและการเรียนรู้

- **ไดอารี่ทุกคืน:** อย่างน้อย 3 บรรทัด (เกิดอะไรขึ้น · ตั้งชื่ออารมณ์ · พรุ่งนี้จะทำอะไร) ตรวจจำนวนคำขั้นต่ำ
- **อ่านหนังสือ:** 5 → 20 หน้า/วัน · หนังสือเล่ม: สุ่มขอรูปเลขหน้า · อีบุ๊ก: เวลาใช้แอปอ่าน
- **ภาษาอังกฤษ:** 15 → 30 นาที/วัน (Spaced repetition, Cepeda 2006) ตรวจด้วยเวลาใช้แอปเรียน + อัดเสียงพูด 1 นาที/วัน ·
  EF SET ทุก 3 เดือน · English Mode (System พูดอังกฤษ + ซับไทย)
- **การเทรด (พฤติกรรมเท่านั้น ไม่เก็บตัวเลขเทรด):** เช็คอารมณ์ 1–10 ก่อนเทรด · เพดานไม้ต่อวัน ·
  พัก 15 นาทีหลังขาดทุน (เควสต์หายใจ cyclic sighing, Balban 2023) · ล็อกแอปเทรดตามกฎ
- **ความมั่นใจ:** ชาเลนจ์เพิ่มระดับทีละขั้น (graded exposure) เช่น อัดเสียงพูด สบตาคนขายของ ทักแชทภาษาอังกฤษ
- **PSS-10** รายเดือน

## 13. เศรษฐกิจในเกมและการเงินจริง

### 13.1 เงิน 2 แบบ

| ชื่อ | คือ | ได้จาก |
|---|---|---|
| **G** | เงินในเกม | เควสต์เท่านั้น (ซื้อด้วยเงินจริงไม่ได้) |
| **VAULT ฿** | เงินเก็บจริง | กันเงินวันรับเงิน (ค่าเริ่มต้น 10–20%) + เงินที่ประหยัดจากงบ |

### 13.2 การเงินจริง

- บันทึกรายจ่าย 2 แตะ (ยอด + หมวด) · งบวัน = งบสัปดาห์ ÷ 7
- กฎ 24 ชม.: ของไม่จำเป็น > 300 บาท และ**ทุกการเติมเกม** ต้องรอ 24 ชม. ใน Wishlist
- หมวดเติมเกม: เพดานต่อเดือน · แสดงผลกระทบ ("เติม 300 = นาฬิกาเลื่อน 4 วัน")
- No-Spend Day · บอสการเงินประจำสัปดาห์ (ไม่เกินงบ 7 วัน)
- บัญชี VAULT แบบบันทึกเพิ่มอย่างเดียว (append-only ledger) แก้ย้อนหลังไม่ได้ มีรายการปรับปรุงแทน
- **Legendary Quest:** ซื้อสมาร์ทวอทช์ภายใน 90 วันจาก Day 0 ด้วยเงิน VAULT (เช็คลิสต์รองรับ Health Connect ก่อนซื้อ)

### 13.3 ร้านค้า

ราคาเทียบรายได้ ≈ 2,400–3,000 G/เดือน:

| ระดับ | ราคา | ความถี่ |
|---|---|---|
| COMMON | 100–300 G | ทุกสัปดาห์ |
| RARE | 500–1,000 G | 2–3 สัปดาห์ |
| EPIC | 1,500–2,000 G | ≈ เดือนละชิ้น |
| LEGENDARY | 3,000–5,000 G + LV 10 | ≈ 2–3 เดือน |

- **AVATAR:** ช่อง หัว · ตัว · ผ้าคลุม · อาวุธ · ออร่า · สัตว์เลี้ยง · ฉากหลัง · กรอบ · ฉายา (ใช้ G อย่างเดียว)
- **REAL REWARD:** ใช้ G + เงินจริงจาก VAULT เช่น กาแฟร้านโปรด · ของหวาน · Cheat Meal (สตรีค 7 วัน) · ดูหนัง ·
  โมเดล/กาชา · โมเดลตัวใหญ่ (LV 10) · ผู้ใช้แก้ราคาและเพิ่มรางวัลเองได้
- **TWIN item:** ไอเทมในเกมผูกกับของจริง (รูป + ราคา) → ซื้อด้วย G → ได้ `PERMIT` →
  ซื้อของจริงด้วย VAULT + แนบรูป → ไอเทมเป็น `REALIZED`
- รางวัลหลังทำเควสต์ (temptation bundling, Milkman 2014): เวลาเล่นเกม/อนิเมะ = ปลดล็อกเมื่อทำเควสต์หลักครบ

## 14. ล็อกแอป (โหมดโหด)

- ตรวจแอปที่เปิดอยู่ด้วย AccessibilityService (`TYPE_WINDOW_STATE_CHANGED`) + สำรองด้วย UsageStats
- หน้าจอ `[ ACCESS DENIED ]` (สไตล์ C) ทับแอปที่ล็อก พร้อมเควสต์ที่เหลือและปุ่มไป QUEST LOG
- **ช่วงล็อก:**
  - ล็อกเช้า: เวลาตื่น → จนกว่าเควสต์เช้าเสร็จ
  - ล็อกฝึก: ถ้าเควสต์ฝึกยังไม่เสร็จ ล็อกตั้งแต่เวลาที่ตั้งไว้ (ค่าเริ่มต้น 18:00) จนกว่าจะเสร็จ
  - ล็อกลงโทษ: ระหว่าง PENALTY QUEST
- ไม่มีปุ่มจ่ายเงินปลดล็อก · วันป่วย 2 ครั้ง/เดือน
- **ไม่ล็อกเด็ดขาด:** โทรศัพท์ · SMS · แผนที่ · แอปธนาคาร · แอปทำงาน (TikTok Studio, CapCut, Meta Business Suite) ·
  โทรฉุกเฉิน (ระบบ Android อนุญาตเสมอ)
- กันปิดระบบ: ระหว่างล็อก บล็อกหน้า "ข้อมูลแอป/ถอนการติดตั้ง" ของ System และหน้าปิด Accessibility
- สิทธิ์หลุด/ถูกปิด → `[ WARNING ]` ทันที + นับเป็นล้มเหลว (ตรวจทุกครั้งที่เปิดเครื่องและทุกเช้า)
